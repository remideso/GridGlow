# GridGlow

A private, browser-based spreadsheet cleaning workspace.

## Run

Open `index.html` in a modern browser. An internet connection is needed once to load the XLSX parser.

## Features

- CSV and XLSX import
- Step-by-step cleaning with previews and undo
- Missing value, duplicate, and text-format cleanup
- Two-file comparison by unique identifier
- XLOOKUP-style enrichment between two spreadsheets with a final CSV download
- Browser-local folders and saved projects
- XLSX exports
- Local-only file processing
